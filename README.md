LoopHero Unreal
Nom: **Les Aventures de Lulu le lapin**
===

Cible: Les enfants de 6ans et +

Histoire: 
===

# Lulu le lapin vit dans la forêt de Carottia. Un jour une sorcière maléfique vola toute la récolte de carottes pour en faire une potion qui va détruire la forêt. Lulu se lance alors dans une quête pleine d'action pour la retrouver et l'en empêcher.

# 

# Gameplay:

Le jeu se présente sous une forme de jeu de l'oie avec une narration linéaire.

===
